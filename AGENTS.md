# AGENTS.md

## Cursor Cloud specific instructions

ExhibitKIT (public name **PatentPreppers ExhibitKit**) is a **local-first, client-side-only** React app built with Vite (React 19). The primary product is exhibit renaming and management for OnCue and TrialDirector. Tamper-evident message exhibits are a secondary, implemented feature and must not lead the title, hero, or metadata. There is no
backend, database, or server-side component — all PDF parsing, renaming, and licensing logic runs
entirely in the browser. Standard commands live in `package.json` (`dev`, `build`, `lint`, `preview`).

Non-obvious notes:

- Dependencies are refreshed automatically by the startup update script (`npm install`); you do not
  need to reinstall them manually.
- Dev server: `npm run dev` serves on `http://localhost:5173/` (Vite default). Use `-- --host` to
  expose it on the network if needed.
- `npm run lint` runs ESLint on the repo. Fix new lint findings rather than treating them as
  environment noise.
- Core functionality depends on browser **File System Access APIs** (`showDirectoryPicker`) for live
  in-place renaming. These require a Chromium-based browser and a user gesture, and are unavailable
  in headless/automated contexts. For testing without a real folder, use **Load Sample Exhibits**.
  That button fetches `/test-packs/starter.zip` and loads those PDFs as `File` objects, so preview
  and ZIP export see real bytes. It does not read `mock_exhibits/`.
- Fictional test packs (Starter, Standard, Large) are generated by `scripts/generate-test-packs.mjs`
  (`npm run test-packs`). Dev startup writes them to gitignored `public/test-packs/`. `npm run build`
  writes them to `dist/test-packs/` for the static deploy. The first generation is the slow part of
  startup and of the production build; a matching stamp skips it locally. Stress and the single-file
  ramp are opt-in (`--packs stress` or `--packs ramp`) and are not published.
- Free is 5 files per batch (`FREE_MAX_FILES_PER_BATCH`). Starter matches that cap. Standard and Large
  do not. ZIP and in-place rename still require Case Pass or Pro. Bates-style filenames use the saved
  choice in `localStorage` key `exhibitkit_bates_mode_v1` (`sequential` by default, or `as-exhibit-id`).
- Optional Stripe checkout link is configured via the `VITE_STRIPE_PAYMENT_LINK` env var (see
  `README.md`). It is not required to run or evaluate the app locally.
- The `python_scripts/` directory contains standalone helper scripts for generating mock files; they
  are not part of the web app runtime. `mock_exhibits/` is not what Load Sample Exhibits reads.
