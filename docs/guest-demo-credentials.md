# Guest demo credentials — law firm 10-day trial

ExhibitKit is **local-first**: there is no cloud login. These credentials activate a **10-day Guest Demo** entitlement in the browser on the workstation where they are entered. Evidence still never leaves that device.

| **Access key (alternate)** | `EKIT-GUEST-PINK-10DY` |
| **Duration** | **10 days** from first activation on that browser |
| **Access level** | Full Pro generation features (multi-exhibit, binder, ZIP, integrity report) |
| **Privacy** | No evidence uploaded; payment system not involved |

## How to activate at the law firm

1. Open ExhibitKit in Chrome/Edge (desktop recommended for large batches).
2. Click **Upgrade** or open **Pricing**.
3. Under **Guest demo (10 days)**, enter:
   - Guest ID: `pinkney.guest`
   - Passphrase: `ExhibitKit-Trial-10`
4. Click **Activate 10-day guest demo**.
5. Or paste access key `EKIT-GUEST-PINK-10DY` in the license key field.

## After 10 days

- Guest Pro features stop for **new** exports.
- Files already saved on the workstation are **not** deleted.
- Upgrade to Case Pass ($39 / 30 days) or Pro perpetual ($149) to continue.

## Notes for parents / firm IT

- This is a **browser-local entitlement**, not a shared firm SaaS account.
- Activating on a shared computer stores the entitlement in that browser’s localStorage.
- To end access early: use **deactivate** / clear site data for ExhibitKit, or wait for expiry.
- Rotate the passphrase after the trial if the key was shared broadly.
